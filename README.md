## 关于这个项目

这是我的 LeetCode Hot100 学习笔记库，也收录了一些相关拓展题。笔记以 Java 为主，正在逐步补充 Python 版本，希望把每道题背后的思路讲清楚，并留下自己从不会到会的过程。

这里既有整理后的题解，也有最初的尝试、卡住的问题和后续复盘。这些记录能帮助下一次遇到相似问题时，重新推导出解法。

- **按算法专题整理**：从哈希、双指针到树、图和动态规划，方便集中练习与复习。
- **保留思考过程**：记录个人解法、错误尝试、疑问，以及优化的原因。
- **对照两种语言**：已补充部分 Java / Python 对照实现，逐步积累常用写法。
- **串联相近题目**：通过知识点总结和拓展题，理解同一种方法如何用于不同问题。

> 哈希和双指针专题已按统一结构整理，七道题均提供 Java / Python 实现。其余专题逐步整理中。

## 目录与题解规范

哈希和双指针专题已采用以下规范，其他专题逐步迁移。现阶段以题目索引中的链接为准。

| 项目 | 约定 | 示例 |
| --- | --- | --- |
| 专题目录 | 两位编号 + 专题名称 | `01.哈希/` |
| 题解文件 | 四位题号 + 官方中文题名 | `0001.两数之和.md` |
| 专题导读 | 在专题目录下提供导航与方法总结 | `01.哈希/README.md` |
| 语言组织 | 同一篇题解内对照 Java / Python | 多种算法分别提供两种语言实现 |
| 学习状态 | 记录在索引或正文中 | 新文件名不再加入 `✔ / ❌` |

整理后的题解依次包含：**题目信息、题意与示例、解题思路、示例推演、代码实现、复杂度分析、易错点与个人复盘、相关题目**。

保留有价值的个人疑问和错误尝试，并说明修正原因。代码注释侧重关键判断与适用条件，方便复习时重新推导。

<a id="usage"></a>
## 如何使用

### 在线阅读

从上方的题目索引选择专题和题目，即可在 GitHub 中阅读 Markdown 笔记。建议按以下方式使用：

1. **先独立尝试**：写下自己的思路，以及暂时无法解决的边界情况。
2. **带着问题读题解**：重点关注数据结构选择、状态含义和算法为什么成立。
3. **关闭题解重写**：在 LeetCode 中独立实现，用样例和边界输入检查理解。
4. **留下复盘记录**：记下这次卡住的原因，隔一段时间再次尝试。

### 本地阅读

```bash
git clone https://github.com/hhhxxw/leecode_hot100.git
cd leecode_hot100
```

使用 VS Code 或支持 Markdown 的笔记工具打开目录即可。部分历史笔记使用 `[[双链]]` 语法，建议配合支持该语法的工具阅读。

仓库以 Markdown 文档为主，无需安装依赖。若要运行笔记中的代码，请复制到对应题目的 LeetCode 编辑器，或自行补充导入、入口及 `ListNode` / `TreeNode` 等定义。目前没有统一的本地运行和自动测试入口。
