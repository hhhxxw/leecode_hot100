## 题意与示例

一排等宽柱子会挡住两侧流出的水。给定各柱的高度，求所有凹槽能容纳的总水量。

| 输入 `height` | 总水量 | 说明 |
| --- | --- | --- |
| `[0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]` | 6 | 多处凹槽的水量相加 |
| `[4, 2, 0, 3, 2, 5]` | 9 | 内部四列分别接到 `2, 4, 1, 2` |
| `[1, 2, 3, 4]` | 0 | 单调上升，无处蓄水 |

数组长度为 `1` 到 `2 × 10^4`，柱高在 `0` 到 `10^5` 之间。

## 解题思路

### 从逐列公式出发

对于下标 `i`，令 `prefixMax[i]` 为 `0` 到 `i` 的最大高度，`suffixMax[i]` 为 `i` 到末尾的最大高度。第 `i` 列的水量为：

```text
min(prefixMax[i], suffixMax[i]) - height[i]
```

两边的最大值都包含当前柱，因此差值一定非负。若为每列单独扫描左右最高柱，整体需要 `O(n²)` 时间。

### 方法一：前后缀最大值

从左到右记录每列的前缀最大值，再从右到左记录后缀最大值。最后根据公式逐列累加。这也可以理解为两个方向的动态规划，每次只依赖上一个已计算的位置。

### 方法二：双指针

`[left, right]` 是尚未结算的闭区间。`leftMax` 是 `left` 左侧已处理柱子的最高值，`rightMax` 是 `right` 右侧已处理柱子的最高值。两侧尚未处理任何柱时，最高值取 `0`。

- 当 `leftMax <= rightMax` 时，处理 `left`。如果当前柱不高于 `leftMax`，右边已知有足够高的挡板，水位就是 `leftMax`。如果当前柱更高，包含当前柱的左侧最高值等于柱高，这一列水量为 `0`。两种情况都可以先更新 `leftMax`，再用 `leftMax - height[left]` 结算。
- 当 `leftMax > rightMax` 时，按对称逻辑处理 `right`，先更新 `rightMax`，再结算该列。

每轮结算一列，再移动对应指针。当两个指针指向同一列时，该列仍在待处理区间内，因此循环条件为 `left <= right`。

### 方法三：单调栈

用栈保存柱子的下标，栈内高度从底到顶非递增。遇到比栈顶高的新柱，说明右侧出现挡板，可以结算栈顶所代表的一层水。

1. 弹出栈顶 `bottom`，它是本次结算的底面。
2. 弹出后若栈为空，当前层缺少左挡板，停止弹栈。
3. 新栈顶 `left` 是左挡板，当前下标 `right` 是右挡板。宽度为 `right - left - 1`，本层高度为 `min(height[left], height[right]) - height[bottom]`。
4. 累加这层水量，继续尝试弹栈，最后将 `right` 入栈。

前两种方法按列计算，单调栈在找到两侧挡板时按层计算。

## 示例推演

用双指针处理 `[3, 0, 2, 0, 4]`。表中的最高值是该轮处理前两侧已知的边界。

| `left` | `right` | `leftMax` | `rightMax` | 处理位置 | 新增水量 |
| --- | --- | --- | --- | --- | --- |
| 0 | 4 | 0 | 0 | 左端 `0` | 0 |
| 1 | 4 | 3 | 0 | 右端 `4` | 0 |
| 1 | 3 | 3 | 4 | 左端 `1` | `3 - 0 = 3` |
| 2 | 3 | 3 | 4 | 左端 `2` | `3 - 2 = 1` |
| 3 | 3 | 3 | 4 | 左端 `3` | `3 - 0 = 3` |

合计接水 `7`。用单调栈看更小的 `[3, 0, 2]`，扫描到 `2` 时弹出中间的 `0`，以两端为挡板，新增 `1 × (2 - 0) = 2`。

## 代码实现

每个代码块都是独立的 `Solution`，提交时选用一种方法。

### 方法一：前后缀最大值 · Java

```java
class Solution {
    public int trap(int[] height) {
        int n = height.length;
        if (n < 3) {
            return 0;
        }

        int[] prefixMax = new int[n];
        int[] suffixMax = new int[n];
        prefixMax[0] = height[0];
        suffixMax[n - 1] = height[n - 1];
        for (int i = 1; i < n; i++) {
            prefixMax[i] = Math.max(prefixMax[i - 1], height[i]);
        }
        for (int i = n - 2; i >= 0; i--) {
            suffixMax[i] = Math.max(suffixMax[i + 1], height[i]);
        }

        int water = 0;
        for (int i = 0; i < n; i++) {
            water += Math.min(prefixMax[i], suffixMax[i]) - height[i];
        }
        return water;
    }
}
```

### 方法一：前后缀最大值 · Python

```python
from typing import List


class Solution:
    def trap(self, height: List[int]) -> int:
        n = len(height)
        if n < 3:
            return 0

        prefix_max = [0] * n
        suffix_max = [0] * n
        prefix_max[0] = height[0]
        suffix_max[n - 1] = height[n - 1]
        for i in range(1, n):
            prefix_max[i] = max(prefix_max[i - 1], height[i])
        for i in range(n - 2, -1, -1):
            suffix_max[i] = max(suffix_max[i + 1], height[i])

        water = 0
        for i in range(n):
            water += min(prefix_max[i], suffix_max[i]) - height[i]
        return water
```

### 方法二：双指针 · Java

```java
class Solution {
    public int trap(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int leftMax = 0;
        int rightMax = 0;
        int water = 0;

        while (left <= right) {
            if (leftMax <= rightMax) {
                leftMax = Math.max(leftMax, height[left]);
                water += leftMax - height[left];
                left++;
            } else {
                rightMax = Math.max(rightMax, height[right]);
                water += rightMax - height[right];
                right--;
            }
        }
        return water;
    }
}
```

### 方法三：单调栈 · Java

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int trap(int[] height) {
        Deque<Integer> stack = new ArrayDeque<>();
        int water = 0;

        for (int right = 0; right < height.length; right++) {
            while (!stack.isEmpty() && height[right] > height[stack.peek()]) {
                int bottom = stack.pop();
                if (stack.isEmpty()) {
                    break;
                }

                int left = stack.peek();
                int width = right - left - 1;
                int depth = Math.min(height[left], height[right]) - height[bottom];
                water += width * depth;
            }
            stack.push(right);
        }
        return water;
    }
}
```

### 方法三：单调栈 · Python

```python
from typing import List


class Solution:
    def trap(self, height: List[int]) -> int:
        stack = []
        water = 0

        for right, right_height in enumerate(height):
            while stack and right_height > height[stack[-1]]:
                bottom = stack.pop()
                if not stack:
                    break

                left = stack[-1]
                width = right - left - 1
                depth = min(height[left], right_height) - height[bottom]
                water += width * depth
            stack.append(right)

        return water
```

## 复杂度分析

设 `n` 为柱子数量。

| 方法 | 时间复杂度 | 辅助空间 | 原因 |
| --- | --- | --- | --- |
| 前后缀最大值 | `O(n)` | `O(n)` | 三趟线性扫描和两个辅助数组 |
| 双指针 | `O(n)` | `O(1)` | 每轮只结算一列，保存两侧最高值 |
| 单调栈 | `O(n)` | `O(n)` | 每个下标最多入栈、出栈各一次 |

## 易错点与个人复盘

- 区分当前柱高与两侧最高值。当前实现用 `leftMax`、`rightMax` 决定结算顺序，证明也依赖这两个量的含义。
- 结算一列前先更新该侧的最高值，否则遇到新最高柱时可能算出负水量。
- 单调栈弹出底面后，先检查是否仍有左边界。宽度要扣除两侧挡板，即 `right - left - 1`。
- 复盘问题：用 `[3, 0, 2, 0, 4]` 推演双指针，解释为什么左右指针相遇时还要结算一列。
