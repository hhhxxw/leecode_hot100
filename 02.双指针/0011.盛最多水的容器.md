## 题意与示例

从一排垂线中选两条作为容器的两侧，返回最大容量。下标 `left`、`right` 之间的容量是 `min(height[left], height[right]) * (right - left)`。

| 输入 `height` | 最大容量 | 说明 |
| --- | --- | --- |
| `[1, 8, 6, 2, 5, 4, 8, 3, 7]` | 49 | 下标 `1` 和 `8` 的宽度为 `7`，水位为 `7` |
| `[1, 1]` | 1 | 只有一组可选边界 |
| `[0, 0, 0]` | 0 | 两边都无法提供水位 |

数组长度为 `2` 到 `10^5`，高度在 `0` 到 `10^4` 之间。

## 解题思路

### 从枚举两条边到排除短边

枚举所有边界组合需要 `O(n²)` 时间。从最左、最右的垂线开始，每轮计算当前容量，再判断哪条边可以排除。

假设左边比右边短或两边同高。固定 `left` 后，把右边界换成任何内部下标 `k`，宽度都比 `right - left` 小，水位仍然最多为 `height[left]`。所以当前容量已经是保留这条左边时能得到的最大值，记录后可排除 `left`。右边较短时可作对称推导。

### 算法步骤

1. 两个指针放到数组两端，最大容量初始为 `0`。
2. 当 `left < right` 时，计算容量并更新最大值。
3. 左边较短就右移 `left`，其余情况左移 `right`。同高时任选一边，本实现固定移动右边。

## 示例推演

以 `[1, 4, 2, 3]` 为例。

| `left` | `right` | 当前容量 | 最大容量 | 移动 |
| --- | --- | --- | --- | --- |
| 0 | 3 | `1 × 3 = 3` | 3 | 左边较短，右移 `left` |
| 1 | 3 | `3 × 2 = 6` | 6 | 右边较短，左移 `right` |
| 1 | 2 | `2 × 1 = 2` | 6 | 右边较短，左移 `right` |

指针相遇后结束，返回 `6`。

## 代码实现

### Java

```java
class Solution {
    public int maxArea(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int maxArea = 0;

        while (left < right) {
            int area = Math.min(height[left], height[right]) * (right - left);
            maxArea = Math.max(maxArea, area);

            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }

        return maxArea;
    }
}
```

### Python

```python
from typing import List


class Solution:
    def maxArea(self, height: List[int]) -> int:
        left = 0
        right = len(height) - 1
        max_area = 0

        while left < right:
            area = min(height[left], height[right]) * (right - left)
            max_area = max(max_area, area)

            if height[left] < height[right]:
                left += 1
            else:
                right -= 1

        return max_area
```

## 复杂度分析

设 `n` 为垂线数量。每轮缩小一个下标，最多执行 `n - 1` 轮。时间复杂度为 `O(n)`，辅助空间为 `O(1)`。

## 易错点与个人复盘

- 容量中的宽度是两个下标之差 `right - left`。
- 先计算当前容量，再排除短边。先移动会漏掉当前这组边界。
- 移动短边的依据是能够排除保留它的其他组合。下一轮的容量仍可能变小，因此要保留扫描过程中的最大值。
- 复盘问题：对 `[1, 4, 2, 3]`，如果一开始移动右指针，为什么会错过容量为 `6` 的组合？
