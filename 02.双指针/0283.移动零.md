## 题意与示例

在原数组中把零集中到末尾，保留非零元素原本的先后顺序。数组长度为 `1` 到 `10^4`，元素可为负数。

| 输入 | 修改后的数组 | 说明 |
| --- | --- | --- |
| `[0, 1, 0, 3, 12]` | `[1, 3, 12, 0, 0]` | 非零元素仍按 `1, 3, 12` 排列 |
| `[0]` | `[0]` | 没有非零元素 |
| `[2, 0, -1]` | `[2, -1, 0]` | 负数也应保留 |

## 解题思路

### 从新数组到原地写入

先收集非零元素，再补齐零，很容易保持顺序。要把这个过程做在原数组上，只需记录下一次应该写到哪里。

- `read` 从左到右扫描输入。
- `write` 指向下一个非零元素的写入位置，也等于已遇到的非零元素数量。

遇到非零值就写入 `nums[write]` 并推进 `write`。扫描结束后，`[0, write)` 已是完整的非零前缀，把 `[write, n)` 填成零。

### 为什么原地写入不会覆盖尚未读取的值？

处理 `read` 前，`write` 等于前 `read` 个位置中非零元素的数量，因此 `write <= read`。写入只会触及当前位置或已经读过的位置。非零值按扫描顺序追加到前缀，原有相对顺序随之保留。

## 示例推演

以 `[0, 1, 0, 3, 12]` 为例，表中只展示已经整理好的前缀。

| `read` | 读到的值 | 处理后的 `write` | 非零前缀 |
| --- | --- | --- | --- |
| 0 | 0 | 0 | `[]` |
| 1 | 1 | 1 | `[1]` |
| 2 | 0 | 1 | `[1]` |
| 3 | 3 | 2 | `[1, 3]` |
| 4 | 12 | 3 | `[1, 3, 12]` |

最后从下标 `3` 开始补零，得到 `[1, 3, 12, 0, 0]`。

## 代码实现

### Java

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int write = 0;
        for (int read = 0; read < nums.length; read++) {
            if (nums[read] != 0) {
                nums[write] = nums[read];
                write++;
            }
        }

        for (int i = write; i < nums.length; i++) {
            nums[i] = 0;
        }
    }
}
```

### Python

```python
from typing import List


class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        write = 0
        for read in range(len(nums)):
            value = nums[read]
            if value != 0:
                nums[write] = value
                write += 1

        for i in range(write, len(nums)):
            nums[i] = 0
```

## 复杂度分析

设 `n` 为数组长度。扫描和补零合计花费 `O(n)` 时间，辅助空间为 `O(1)`。

## 易错点与个人复盘

- `write` 表示下一个可写位置，因此补零从 `write` 开始。下标 `write - 1` 已经放好了最后一个非零值。
- 判断条件使用 `value != 0`。负数同样需要移动到前缀。
- 读写指针也可以做一次扫描的交换版。当 `write < read` 时，`write` 处恰好是待后移的零，可以与当前非零值交换。比较写入次数时要考虑输入分布。上面的压紧版写入 `n` 次，交换版若跳过同位置交换，每移动一个非零值写入两次。
- 复盘问题：对全零、没有零、零都在尾部三种数组，两个指针分别如何移动？
