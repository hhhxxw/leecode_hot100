# 双指针：读写位置与缩小搜索范围

[返回项目首页](../README.md)

双指针的关键是明确每个指针的职责，以及移动后可以安全丢掉哪些候选。移动零用同向指针维护已整理的前缀，其余三题从两侧逐步缩小范围。

## 题目导航

| 题号 | 题目 | 难度 | 核心方法 | 语言 |
| --- | --- | --- | --- | --- |
| 283 | [移动零](0283.移动零.md) | 简单 | 读写指针压紧非零元素，再补零 | Java / Python |
| 11 | [盛最多水的容器](0011.盛最多水的容器.md) | 中等 | 计算当前面积后排除短边 | Java / Python |
| 15 | [三数之和](0015.三数之和.md) | 中等 | 排序后固定一个数，用双指针找另外两个数 | Java / Python |
| 42 | [接雨水](0042.接雨水.md) | 困难 | 按两侧已知最高值结算水量，也提供前后缀最大值和单调栈 | Java / Python |

## 方法之间的联系

| 题目 | 指针分别表示什么 | 何时移动 |
| --- | --- | --- |
| 移动零 | `read` 扫描元素，`write` 指向下一个非零写入位置 | `read` 每次前进，`write` 只在写入非零值后前进 |
| 盛最多水的容器 | `left`、`right` 是当前两条候选边 | 记录当前面积后，移动较短的一边 |
| 三数之和 | 固定 `i` 后，`left`、`right` 寻找剩下两个数 | 和偏小就增大左值，偏大就减小右值，命中后跳过重复值 |
| 接雨水 | `left`、`right` 是尚未结算区间的两端 | 用较小的已知侧边最高值判断哪一端的水位已经确定 |

第 11 题只选两根柱子，中间的柱子不参与面积计算。第 42 题逐列计算积水，每列要看左右的最高柱。两题都受较低边界限制，但比较的量不同。

## Java / Python 常用写法

| 操作 | Java | Python |
| --- | --- | --- |
| 最右端下标 | `nums.length - 1` | `len(nums) - 1` |
| 原地升序排序 | `Arrays.sort(nums);` | `nums.sort()` |
| 取两个值中较小者 | `Math.min(a, b)` | `min(a, b)` |
| 原地写入 | `nums[write] = nums[read];` | `nums[write] = nums[read]` |

## 复习时检查什么

1. 每次移动指针前，已经得到答案、确定水量，还是排除了一批候选？
2. 哪些位置已经处理，哪些仍在搜索范围内？指针相遇时还要处理最后一个位置吗？
3. 遇到重复值时，题目要求保留次数、保持原有顺序，还是对输出去重？
