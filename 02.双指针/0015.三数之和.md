## 题意与示例

从三个不同位置取数，返回所有和为零的三元组。输出按数值组合去重，结果顺序不限。

| 输入 `nums` | 一种合法输出 | 说明 |
| --- | --- | --- |
| `[-1, 0, 1, 2, -1, -4]` | `[[-1, -1, 2], [-1, 0, 1]]` | 两个 `-1` 来自不同下标 |
| `[0, 1, 1]` | `[]` | 没有符合条件的组合 |
| `[0, 0, 0, 0]` | `[[0, 0, 0]]` | 不同下标组合得到相同数值，只输出一次 |

数组长度为 `3` 到 `3000`，元素在 `[-10^5, 10^5]` 内。

## 解题思路

### 从三层枚举到固定一位

枚举三个下标需要 `O(n³)` 时间。排序后固定 `nums[i]`，就能利用剩余元素的单调性查找另外两个数。每轮从 `left = i + 1`、`right = n - 1` 开始，保证三个下标互不相同。

### 为什么可以移动一侧？

- 三数和小于零时，当前 `right` 已经是剩余范围里的最大值。保留 `left`、把 `right` 换到更左的位置，只会使和更小或不变。排除当前 `left`，向右移动。
- 三数和大于零时，当前 `left` 已经是剩余范围里的最小值。保留 `right`、把 `left` 换到更右的位置，只会使和更大或不变。排除当前 `right`，向左移动。
- 三数和等于零时，记录组合。固定其中一侧的值，能与它配成零的另一侧值也已经确定。跳过两侧与当前值相同的元素，再继续搜索。

### 在哪些位置去重？

外层只处理每个起始值第一次出现的位置。相同起始值在更后面的位置只会缩小可选范围。内层找到答案后，跳过两侧相同的值，避免在同一轮输出重复组合。

排序后，`nums[i] > 0` 时，剩下的数都为正，可以结束外层循环。

## 示例推演

`[-1, 0, 1, 2, -1, -4]` 排序后为 `[-4, -1, -1, 0, 1, 2]`。

| 固定值 | `nums[left]` | `nums[right]` | 三数和 | 操作 |
| --- | --- | --- | --- | --- |
| `-4` | `-1` | `2` | `-3` | 左指针右移。本轮即使选最大的 `1` 和 `2`，和也小于零 |
| `-1` | `-1` | `2` | `0` | 记录 `[-1, -1, 2]`，向内移动两侧 |
| `-1` | `0` | `1` | `0` | 记录 `[-1, 0, 1]`，两侧交错后结束本轮 |

下一个起始值仍为 `-1`，外层跳过。后续以 `0` 开始的一轮也找不到新组合。

## 代码实现

### Java

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> result = new ArrayList<>();

        for (int i = 0; i < nums.length - 2; i++) {
            if (nums[i] > 0) {
                break;
            }
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = nums.length - 1;
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                if (sum < 0) {
                    left++;
                } else if (sum > 0) {
                    right--;
                } else {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    while (left < right && nums[left] == nums[left + 1]) {
                        left++;
                    }
                    while (left < right && nums[right] == nums[right - 1]) {
                        right--;
                    }
                    left++;
                    right--;
                }
            }
        }

        return result;
    }
}
```

### Python

```python
from typing import List


class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        result = []

        for i in range(len(nums) - 2):
            if nums[i] > 0:
                break
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            left = i + 1
            right = len(nums) - 1
            while left < right:
                total = nums[i] + nums[left] + nums[right]
                if total < 0:
                    left += 1
                elif total > 0:
                    right -= 1
                else:
                    result.append([nums[i], nums[left], nums[right]])
                    while left < right and nums[left] == nums[left + 1]:
                        left += 1
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1
                    left += 1
                    right -= 1

        return result
```

## 复杂度分析

- **时间复杂度为 `O(n²)`**。固定一个起始值后，两个指针合计最多移动 `O(n)` 次，包括为去重而跳过的位置。
- **辅助空间**。双指针扫描只用 `O(1)` 辅助空间，整体还要计入排序开销。Python 的 `list.sort()` 最坏使用 `O(n)` 临时空间，Java 的 `Arrays.sort(int[])` 空间开销取决于 JDK 的排序实现。结果列表另占 `O(k)` 空间，`k` 为返回的三元组数量。

## 易错点与个人复盘

- 相同数值可以出现在一个三元组里。`[0, 0, 0]` 合法，因为三个值来自不同下标。
- 外层对起始值去重，内层在记录答案后对两侧去重。提前跳过两侧相同的值前，要确认不会跳过唯一的配对机会。
- 两种实现都会排序原数组。需要保留输入顺序时，可先复制数组再排序，并计入复制的空间开销。
- 复盘问题：找到 `[-1, 0, 1]` 后，为什么可以同时移动两个指针？
