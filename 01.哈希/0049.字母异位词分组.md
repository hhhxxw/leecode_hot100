## 题意与示例

把字符串按“各字符出现次数相同”分组。字符顺序可以不同，但字符种类和数量都必须一致。组间及组内返回顺序均不限。

| 输入 | 一种合法输出 |
| --- | --- |
| `["eat", "tea", "tan", "ate", "nat", "bat"]` | `[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]` |
| `[""]` | `[[""]]` |
| `["a"]` | `[["a"]]` |

关键约束：字符串数量为 `1` 到 `10^4`，每个字符串长度为 `0` 到 `100`，字符仅包含小写英文字母。

## 解题思路

### 先找到分组依据

逐一比较当前字符串与已有字符串，会重复进行字符统计。可以把每个字符串转换成一个统一的“特征键”：

> 两个字符串互为字母异位词，当且仅当它们生成的键相同。

哈希表保存“特征键 → 原字符串列表”。遍历时计算键，把原字符串加入对应分组。这里有两种生成键的方法。

### 方法一：排序键

将字符串中的字符排序，例如 `eat`、`tea`、`ate` 都变成 `aet`。

1. 对当前字符串的字符排序，得到键。
2. 如果键对应的分组不存在，先创建空列表。
3. 把原字符串加入分组。
4. 返回所有分组。

相同的字符及数量排序后一定相同；反过来，排序结果相同也意味着字符及数量相同，因此不会把不同类的字符串分在一起。

此方法直观，适合作为第一种实现。

### 方法二：字符计数键

题目限定为小写英文字母，可以用长度为 `26` 的计数数组表示字符组成。`eat`、`tea`、`ate` 的 `a`、`e`、`t` 位置均为 `1`，其他位置为 `0`。

整体流程不变，只把排序替换为字符计数。完整的计数向量相同，当且仅当两个字符串互为字母异位词。

- **Java**：将计数数组通过 `Arrays.toString(counts)` 转成字符串作为键。该表示包含逗号等分隔信息，不会产生数字直接拼接的歧义。不能直接将普通 `int[]` 当作按内容比较的键，因为数组默认按对象身份判断相等。
- **Python**：使用 `tuple(counts)` 作为键。整数元组可哈希，列表 `list` 可变且不可哈希，不能直接作为字典键。

这里保存的是完整特征，不是把单一哈希值当作特征。底层哈希值即使发生碰撞，映射仍会通过键的相等性区分分组。

## 示例推演

以排序键法处理 `["eat", "tea", "tan", "ate"]`：

| 当前字符串 | 排序键 | 更新后的对应分组 |
| --- | --- | --- |
| `eat` | `aet` | `["eat"]` |
| `tea` | `aet` | `["eat", "tea"]` |
| `tan` | `ant` | `["tan"]` |
| `ate` | `aet` | `["eat", "tea", "ate"]` |

使用计数键时，字符组成相同的字符串仍会落入相同分组。空字符串的排序键为 `""`，计数键为全零向量，两种方法都能自然处理。

## 代码实现

以下四个代码块各自独立，提交时选择一种方法、对应语言的一个代码块。

### 方法一：排序键 · Java

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> groups = new HashMap<>();

        for (String str : strs) {
            char[] chars = str.toCharArray();
            Arrays.sort(chars);
            String key = new String(chars);
            // 保存原字符串，而不是排序后的键。
            groups.computeIfAbsent(key, k -> new ArrayList<>()).add(str);
        }

        return new ArrayList<>(groups.values());
    }
}
```

### 方法一：排序键 · Python

```python
from collections import defaultdict
from typing import List


class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = defaultdict(list)

        for s in strs:
            key = "".join(sorted(s))
            # 保存原字符串，而不是排序后的键。
            groups[key].append(s)

        return list(groups.values())
```

### 方法二：字符计数键 · Java

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> groups = new HashMap<>();

        for (String str : strs) {
            int[] counts = new int[26];
            for (int i = 0; i < str.length(); i++) {
                counts[str.charAt(i) - 'a']++;
            }
            // 序列化完整计数向量，保留每个计数的边界。
            String key = Arrays.toString(counts);
            groups.computeIfAbsent(key, k -> new ArrayList<>()).add(str);
        }

        return new ArrayList<>(groups.values());
    }
}
```

### 方法二：字符计数键 · Python

```python
from collections import defaultdict
from typing import List


class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = defaultdict(list)

        for s in strs:
            counts = [0] * 26
            for ch in s:
                counts[ord(ch) - ord("a")] += 1
            # 将可变列表转换为可哈希的整数元组。
            key = tuple(counts)
            groups[key].append(s)

        return list(groups.values())
```

## 复杂度分析

设字符串数量为 `n`，最大字符串长度为 `K`，字符集大小为 `Σ = 26`。令 `L = max(1, K)`，使全部为空字符串时的复杂度也有明确含义。以下计入分组列表保存的引用，原字符串内容不额外复制；哈希操作按平均情况分析，并计入复合键的处理成本。

| 方法 | 时间复杂度上界 | 空间复杂度上界 |
| --- | --- | --- |
| 排序键（两种语言） | `O(nL log(L + 1))` | `O(nL)` |
| 字符计数键（Python） | `O(n(L + Σ))` | `O(nΣ + n)` |
| 字符计数键（Java） | `O(n(L + Σ))` | `O(nΣ log(L + 1) + n + L + Σ)` |

排序法主要花费在逐个字符串排序。Python 计数键固定包含 `26` 个整数，构造和哈希都需要 `O(Σ)` 时间。

Java 将计数序列化为十进制字符串，每个计数最多占 `O(log(L + 1))` 个字符，因此空间上保留这一因素。生成一个键的长度也可由 `O(L + Σ)` 上界，因为所有计数之和不超过 `K`。这使计数法的总时间仍可写为 `O(n(L + Σ))`。

计数法避免排序，但对于较短字符串，具体速度仍受语言实现和常数开销影响，不承诺它总比排序法更快。

## 易错点与个人复盘

- **比较字符数量，不只是种类**：`ab` 与 `aab` 不能分在一组，用字符集合做键会丢失数量信息。
- **Java 数组不是按内容比较的键**：分别创建的两个相同 `int[]` 默认也不相等。
- **计数序列化必须可区分边界**：直接拼接数字会把 `[1, 11, ...]` 与 `[11, 1, ...]` 混淆，使用明确分隔的表示。
- **每个字符串重新计数**：复用数组却不清零，会把之前字符串的信息带入当前键。
- **保留重复字符串**：输入 `["a", "a"]` 的结果应包含两个 `a`，不能对分组内容去重。
- **输出顺序不固定**：核对结果时比较分组内容，不能仅因 Java 的分组顺序不同就认为解法错误。
- **适用条件**：计数版本依赖小写英文字母约束，不能直接用于任意字符集。
- **复盘问题**：为什么排序键和计数键都能唯一表示一类异位词？如果允许任意字符，计数键该如何调整？

建议核对的边界输入：`[""]`、`["", ""]`、`["a", "a", "b"]`、`["ab", "aab"]`，以及字符数量超过一位数的字符串。
