# 哈希：查找、分组与去重

[返回项目首页](../README.md)

哈希结构把“逐个寻找”变成“按键查找”。这个专题用三道题练习三种用法：保存已遍历的信息、构造分组特征、去重并判断元素是否存在。

## 题目导航

| 题号 | 题目 | 难度 | 核心方法 | 语言 |
| --- | --- | --- | --- | --- |
| 1 | [两数之和](0001.两数之和.md) | 简单 | 哈希表保存数值与下标 | Java / Python |
| 49 | [字母异位词分组](0049.字母异位词分组.md) | 中等 | 排序键 / 字符计数键分组 | Java / Python |
| 128 | [最长连续序列](0128.最长连续序列.md) | 中等 | 哈希集合去重，从序列起点扩展 | Java / Python |

建议按表格顺序阅读。三篇分别关注：**存什么、怎样设计键、怎样避免重复计算**。

## 方法之间的联系

| 题目 | 键是什么 | 保存什么 | 省去了什么操作 |
| --- | --- | --- | --- |
| 两数之和 | 已遍历的数值 | 该数值的下标 | 为当前数再次扫描数组找补数 |
| 字母异位词分组 | 字符串的规范化特征 | 具有相同特征的字符串列表 | 与每个已有字符串逐一比较 |
| 最长连续序列 | 数值本身 | 只保存是否存在 | 扫描数组判断相邻整数是否存在 |

需要“键 → 附加信息”时选择映射；只关心“是否存在”时选择集合。

## Java / Python 常用写法

| 操作 | Java | Python |
| --- | --- | --- |
| 创建映射 | `Map<Integer, Integer> seen = new HashMap<>();` | `seen = {}` |
| 判断键存在 | `seen.containsKey(key)` | `key in seen` |
| 读取值 | `seen.get(key)` | `seen[key]` |
| 写入或更新 | `seen.put(key, value);` | `seen[key] = value` |
| 创建分组 | `groups.computeIfAbsent(key, k -> new ArrayList<>())` | `groups[key]`，其中 `groups = defaultdict(list)` |
| 创建集合 | `Set<Integer> values = new HashSet<>();` | `values = set(nums)` |
| 判断元素存在 | `values.contains(value)` | `value in values` |

Java 的映射读取缺失键通常返回 `null`；Python 普通字典直接读取缺失键会抛出 `KeyError`。这些写法中的导入与完整上下文见各题代码。

哈希查找、插入通常按平均或期望 `O(1)` 分析；字符串和元组等复合键还需要计算其构造、哈希及比较成本，不能忽略键的长度。
